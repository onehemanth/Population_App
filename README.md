# Population App (Phase 1 / Step 1)

Minimal Vite + React + Tailwind + Leaflet setup with a full-screen map.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL on desktop or mobile browser.

## Deploy

### GitHub
1. Commit and push this repository.
2. Keep the default `main` (or chosen) branch as deployment source.

### Vercel
1. Import this GitHub repo into Vercel.
2. Framework preset: **Vite**.
3. Build command: `npm run build`
4. Output directory: `dist`
5. Deploy.

The app is mobile-friendly by default (`viewport` meta tag + full-screen responsive map container).
